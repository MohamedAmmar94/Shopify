===================== Naming Conventions===============================
Folders                     => kebab-case           => components/auth-pages 
React Components            => PascalCase           => UserProfile.tsx
Pages                       => PascalCase           => HomePage.tsx
Hooks                       => camelCase + use      => useAuth
Functions & Variables       => camelCase            => getMovies()
Types & Interfaces          => PascalCase           => MovieResponse 
Constants                   => UPPER_SNAKE_CASE     => API_BASE_URL
